# Restaurant Victor
Добро пожаловать в репозиторий сайта ресторана **Victor**. Сайт представляет собой интерактивную витрину ресторана, где эстетика минимализма встречается с дерзким и остроумным контентом. 

1. Склонировать - ```git clone https://github.com/Felddo/Restaurant-Victor.git```
2. Перейти в папку - ```cd Restaurant-Victor```
3. Скачать все библиотеки  - ```npm install```
4. Запустить код - ```npm run dev```
