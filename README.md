Сайт для прямой аренды трех дизайнерских квартир во Владивостоке. Проект ориентирован на удобство пользователя, минималистичный дизайн и быструю проверку доступности дат.

# Основные возможности
1. Каталог квартир: Каждая квартира имеет индивидуальную страницу с детальным описанием.
2. Интерактивный календарь: Актуальная информация о занятых и свободных датах (обновление каждые 15–30 минут).
3. Bento-правила: Условия проживания оформлены в современном стиле Bento Grid для легкого чтения.
4. Адаптивность: Сайт полностью оптимизирован под мобильные устройства для удобного бронирования «на ходу».
5. Прямая связь: Быстрый переход в мессенджеры для подтверждения бронирования.
